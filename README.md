# Library Management System (SCRUM-237)

A centralized Library Management System enabling patrons to search and borrow books, and administrators to manage members, inventory stock, and loan records.

## Features
- **Book Catalog & Multi-Criteria Search**: Search books across titles, authors, genres, and ISBNs with real-time stock indicators.
- **Patron Management**: User registration, profile management, and role-based access control (Admin & Patron).
- **Loan Workflows**: Atomic checkouts, returns, and renewals with real-time inventory adjustments.
- **Inventory & Overdue Tracking**: Real-time stock counters and overdue loan monitoring dashboard.

---

### Requirements
- Python 3.11+
- Virtualenv / uv

### Installation
```bash
cd server
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Environment Variables
Copy the example environment configuration:
```bash
cp .env.example .env
```

### Running Tests
```bash
pytest server/tests -v
```

### Starting the Server
```bash
uvicorn server.main:app --reload --host 0.0.0.0 --port 8000
```

## Full-Stack Local Development

### Default Ports
- **Backend API**: `http://localhost:8000` (Swagger Docs: `http://localhost:8000/docs`)
- **Frontend SPA**: `http://localhost:5173`

### Pre-Seeded Test Accounts
- **Patron User**: `test@example.com` / `testpassword`
- **Admin User**: `admin@example.com` / `adminpassword`

### Prerequisites
- Python 3.9+
- pip and venv

### Setup

1. Create and activate virtual environment:
```bash
python -m venv server/.venv
# On Windows:
server\.venv\Scripts\activate
# On macOS/Linux:
source server/.venv/bin/activate
```

2. Install dependencies:
```bash
cd server
pip install -r requirements.txt
cd ..
```

### Running Tests
```bash
cd server
python -m pytest -v
cd ..
```

### Starting the Development Server
```bash
# Run from the repo root so that `from server.X` imports resolve correctly
python -m uvicorn server.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at `http://localhost:8000`
API documentation: `http://localhost:8000/docs`

## Full-Stack Local Development

To run both backend and frontend together locally:

### 1. Environment Setup
```bash
# Copy the example environment file
cp .env.example .env
```

### 2. Start the Backend (Terminal 1)
```bash
python -m venv server/.venv
source server/.venv/bin/activate  # On Windows: server\.venv\Scripts\activate
pip install -r server/requirements.txt
python -m uvicorn server.main:app --reload --host 0.0.0.0 --port 8000
```
Backend API: `http://localhost:8000` | API Docs: `http://localhost:8000/docs`

### 3. Start the Frontend (Terminal 2)
```bash
cd client
npm install
npm run dev
```
Frontend: `http://localhost:5173`

The frontend connects to the backend API at `http://localhost:8000` by default via the `VITE_API_BASE_URL` environment variable.

### 4. Test Credentials
If the app has authentication, the backend seeds ready-to-use accounts on startup
(idempotent). These are guaranteed logged-in-able — every activation/verification
gate (`is_active`, `is_verified`, `email_verified`, `disabled`) is set to the
permissive value, so no manual DB step is needed:
- **Regular user** — Email: `test@example.com`, Password: `testpassword`
- **Admin user** (only when the app has roles/RBAC) — Email: `admin@example.com`, Password: `adminpassword`, role: `admin`

Passwords are stored hashed with the app's own hashing utility (never in plaintext).

| Frontend | 5173 | http://localhost:5173      |
| API Docs | 8000 | http://localhost:8000/docs |
