# Project Features

## SCRUM-145 - Shivji Temple Management System

### Feature Summary
Allows temple administrators and devotees to manage devotee registrations, book poojas/sevas online with slot availability, track donations with automated e-receipts, and view administrative operational dashboards.

### Key Features
- Devotee Management & Authentication
- Pooja & Seva Online/Offline Booking System
- Donation Tracking & Digital E-Receipt Generation
- Daily Ritual & Temple Event Scheduling Dashboard
