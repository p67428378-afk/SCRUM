# Project Features

## SCRUM-217 - Movie and Series Management System (Netflix-like Platform)

### Feature Summary
This feature allows subscribers to browse, search, stream, and manage watchlists for movies and TV series, while giving administrators full management over media catalogs and metadata.

### Key Features
- Media Catalog & Metadata Management for movies and TV series
- User Browsing, Filtering, and Search by title, genre, or actor
- Video Streaming with playback controls and watch history tracking
- Personal Watchlist management and media recommendations
