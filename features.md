# Project Features

## SCRUM-161 - Furniture Selling Portal - E-Commerce Platform

### Feature Summary
An e-commerce furniture selling portal that allows users to discover, customize, purchase home furniture online, manage their cart, and track orders.

### Key Features
- Product catalog with categories, filtering (price, material, color), and keyword search
- Product detail pages with high-res images, material specifications, customization options, and inventory stock status
- Interactive shopping cart with item quantity updates, promo code application, and tax/shipping estimation
- Multi-step checkout process with address selection, payment method integration, and order summary
- User authentication and profile management for order history, tracking, and wishlists
