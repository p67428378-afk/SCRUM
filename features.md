# Project Features

## SCRUM-114 - Continent and Country Portfolio Display

### Feature Summary
An interactive web application allowing portfolio viewers to explore continents, search/filter countries, and inspect detailed portfolio metrics for each country.

### Key Features
- Interactive Continent Grid and Navigation
- Detailed Country Portfolio Overview & Metrics
- Real-time Country Search and Continent Filtering
- Full-Stack RESTful API integration using FastAPI and React
