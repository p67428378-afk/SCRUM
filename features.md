# Project Features

## SCRUM-233 - Village Management System - Core Platform Implementation

### Feature Summary
A full-stack web application enabling village residents to book facilities, view announcements, and submit maintenance tickets, while enabling village administrators to manage resident profiles, approve bookings, broadcast notices, and track service requests.

### Key Features
- Resident Management & Profile Directory with Role-Based Access Control (Admin, Resident, Staff)
- Facility Booking System with real-time slot conflict prevention and transaction locks
- Village Announcement Board categorized by urgency (Info, Warning, Emergency)
- Service Request & Maintenance Ticket Tracking with status updates and staff assignment
