# Project Features

## SCRUM-31 - Build a Museum Tour Management System

### Feature Summary
A full-stack Museum Tour Management System that allows visitors to book guided tours, administrators to schedule tours and assign guides, and guides to track visitor attendance, all while enforcing real-time capacity limits.

### Key Features
- Tour Scheduling & Guide Assignment
- Visitor Booking & Capacity Control
- Attendance Recording & Check-in
- Role-Based Access Control (RBAC) & Authentication
