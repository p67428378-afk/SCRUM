# Project Features

## SCRUM-237 - Library Management System - Book Catalog, Patron Management, and Loan Workflows

### Feature Summary
A comprehensive web-based Library Management System that allows library patrons to discover, search, and borrow books, while empowering administrators and staff to manage patron profiles, catalog inventory, track checkouts/returns, and monitor overdue loans.

### Key Features
- Book Catalog & Search: Browse, filter, and search books by title, author, ISBN, or genre.
- Patron Management: Create, view, update, and manage member profiles and borrowing history.
- Loan Workflows: Checkout, return, and renew books with automatic status updates and due date tracking.
- Inventory Tracking: Real-time tracking of book availability, stock counts, and overdue loans.
