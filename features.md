# Project Features

## SCRUM-272 - DG Cluster Assortment Advisor Dashboard

### Feature Summary
A decision-support tool for Dollar General category managers to decide which Snacks products to add, keep, swap, or remove in Small Town Value Cluster stores.

### Key Features
- KPI Header Strip displaying Sales per linear ft, Private Brand %, In-Stock Rate, and Shelf Capacity.
- SKU Performance Table listing Snacks SKUs with performance metrics and status badges (GROW, MAINTAIN, SWAP, REDUCE).
- Scenario Selector with side-by-side Conservative, Balanced (pre-selected), and Aggressive option cards that update the review panel inline upon selection.
- Approval Review Panel showing selected scenario summary, SKU action list, guardrail status checks, and Submit button.
- Inline Confirmation presenting audit-trail summary upon submission within the same screen.
