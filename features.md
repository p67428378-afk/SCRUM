# Project Features

## SCRUM-144 - Manage Grocery Inventory and Stock Levels

### Feature Summary
This feature allows Store Managers to manage grocery items, track inventory levels in real-time, perform manual stock adjustments with an audit log, and view low-stock alerts on a responsive dashboard.

### Key Features
- Grocery Item CRUD Operations
- Real-Time Stock Tracking and Low Stock Alerts
- Stock Adjustment and Audit Log
- Responsive Inventory Dashboard
