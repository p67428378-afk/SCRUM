# Project Features

## SCRUM-125 - Core Cat Marketplace: Listings, Search, and Buyer-Seller Inquiry System

### Feature Summary
A platform where users can browse available cats, view detailed profiles, and contact sellers directly to make inquiries, while sellers can list cats and manage inquiries.

### Key Features
- Cat Catalog & Search: Browse available cats with advanced filters (breed, age, gender, price) and text search.
- Cat Detail View: View rich profiles of cats including images, health status, and seller details.
- Contact Seller Form: Submit secure inquiries for specific cats directly to their sellers.
- Seller Listing Management: Authenticated sellers can list, update, and delete cat profiles, and view received inquiries.
