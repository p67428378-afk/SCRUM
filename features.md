# Project Features

## SCRUM-269 - Library Management System - Book Catalog, Member Management, and Borrowing Workflows

### Feature Summary
Enables library staff to manage book inventory and patrons to search, borrow, return books, and handle overdue fine payments through a web application.

### Key Features
- Book Catalog Management: Search, filter, add, update, and remove books with ISBN, title, author, category, and quantity tracking.
- Member Management: Register new patrons, update member profiles, track borrowing history, and manage membership statuses.
- Borrowing & Returning Workflows: Issue books to active members, process book returns, extend loan periods, and track due dates.
- Fine & Overdue Management: Automatically calculate overdue fines based on configured daily rates and manage fee payments.
- Role-Based Access Control: Differentiate access between Patrons and Staff/Admins.
