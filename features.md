# Project Features

## SCRUM-68 — Task Management Application with User Authentication, Task CRUD, and Interactive Dashboard

### Feature Summary
Allows users to register/login, manage personal tasks with priorities and due dates, and monitor completion progress via a real-time dashboard.

### Key Features
- Secure JWT User Authentication (Registration, Login, Password Hashing, Token Refresh)
- Full Task CRUD Operations (Create, Read, Update, Delete with Priorities and Due Dates)
- Task Filtering, Searching, Sorting, and Paginated Listing
- Interactive Analytics Dashboard with Visual Task Statistics and Completion Metrics
- Responsive React/Tailwind Frontend and FastAPI RESTful Backend
