# Project Features

## SCRUM-214 - Build Cafe Management System Portal

### Feature Summary
A full-stack Cafe Management System Portal allowing cafe staff and managers to update menus, manage live order queues, handle table reservations, and monitor sales analytics.

### Key Features
- Menu Management with category filtering and real-time stock toggles
- Live Order Processing with status tracking and automated tax/total calculation
- Table Layout & Reservation Management to prevent double-booking
- Dashboard Analytics for sales tracking, active orders, and item popularity
