# Project Features

## SCRUM-247 - Actress Portfolio Website

### Feature Summary
Provides a professional web platform where casting directors, agents, and fans can view headshots, media reels, acting credits, biography, and submit booking/contact inquiries.

### Key Features
- Media Gallery & Video Reel Integration with lightboxing
- Filmography & Credit Management categorized by Film, TV, Theater, Commercials
- Contact & Inquiries Form with validation and database storage
- Responsive & Modern UI/UX layout optimized for mobile, tablet, and desktop
