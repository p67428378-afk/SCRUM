# Project Features

## SCRUM-162 - Build a Dog Selling Portal

### Feature Summary
A web platform that enables dog sellers to publish and manage detailed listings of dogs for sale and allows potential buyers to search, filter, view listings, and directly contact sellers.

### Key Features
- Dog Listings Management (create, update, view, delete listings with breed, age, price, health records, location, and photos)
- Search & Filtering (filter by breed, age range, price range, location, and seller rating)
- Seller Contact & Inquiry (direct messaging/contact requests via secure form)
