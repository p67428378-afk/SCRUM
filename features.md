# Project Features

## SCRUM-239 - Build Drugs Management System

### Feature Summary
A full-stack web application allowing users to view, search, add, update, and delete drug items, receive automatic low stock and near expiry alerts, and visualize inventory metrics on an interactive dashboard.

### Key Features
- Drug Inventory Management (CRUD operations with name, generic name, dosage, manufacturer, batch number, stock quantity, expiration date, category, unit price)
- Low Stock (<50 units) & Expiration (<30 days) Alert System
- RESTful API Endpoints (/api/v1/drugs) with FastAPI and PostgreSQL
- Responsive React 18 UI with Vite, Tailwind CSS, search filtering, metric cards, and modal forms
