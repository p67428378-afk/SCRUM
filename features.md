# Project Features

## SCRUM-159 - Expense Tracker Application

### Feature Summary
An expense tracking application that allows users to record income/expense transactions, assign categories, search and filter entries, and view visual spending breakdowns.

### Key Features
- Expense and Income Tracking (add, edit, delete entries)
- Category Management (predefined and custom categories)
- Financial Dashboard & Summaries (visual spending breakdown, balance calculations)
- Data Filtering and Search (filter by category, date range, type)
