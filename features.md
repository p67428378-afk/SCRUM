# Project Features

## SCRUM-221 - Books Management System - Core Inventory & Search Service

### Feature Summary
Allows library and bookstore managers to maintain book inventory with search, filtering, and CRUD operations.

### Key Features
- Book Catalog Management (CRUD operations)
- Search and Filtering (keyword search, category filter, pagination)
- Data Validation & Error Handling (ISBN uniqueness, non-negative price/stock, standard HTTP errors)
