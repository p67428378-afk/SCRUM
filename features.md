# Project Features

## SCRUM-271 - DG Cluster Assortment Advisor Dashboard

### Feature Summary
A single consolidated dashboard screen providing category managers with KPI cards, a SKU performance table with status badges, side-by-side scenario selection (Conservative/Balanced/Aggressive), an approval review panel with guardrail checks, and inline submit confirmation with audit trail.

### Key Features
- KPI Header Strip showing sales per linear ft, private brand %, in-stock rate, and shelf capacity
- SKU Performance Table with performance metrics and color-coded status badges (GROW / MAINTAIN / SWAP / REDUCE)
- Scenario Selector Cards for Conservative, Balanced, and Aggressive scenarios with pre-selected Balanced default
- Approval Review Panel with scenario summary, SKU action list, guardrail status checks, and Submit button
- Inline Confirmation & Audit Trail displaying submission success banner/modal and logging audit metrics
